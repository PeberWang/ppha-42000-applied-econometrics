# Proofs

Systematic write-ups of theorem and proposition proofs from the course.

## Conventions

- **One claim per file**, named `theorem-<slug>.md` (e.g. `theorem-slutsky-equation.md`).
- Structure each file as:
  1. **Statement** — the theorem/proposition, self-contained.
  2. **Proof** — the argument, with every nontrivial step justified.
  3. **Source** — MWG chapter/section or lecture-note page, plus a note on any gap you filled.
- Use LaTeX math: inline `$...$`, display `$$...$$` or `\begin{...}`.
- If a proof depends on an earlier result, link to it with a relative link.
- Prefer complete, checkable proofs over sketches; mark known gaps explicitly with a
  `> **Gap:**` blockquote.
