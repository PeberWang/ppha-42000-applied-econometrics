# Notes

Self-written course notes, in LaTeX or Markdown.

The live source is maintained in the course folder at `../../LaTeX-notes/`; files placed
here are the versions shared publicly. When you update a note, copy the new version in so
the published copy stays current.

## Conventions

- File name mirrors the lecture or chapter, e.g. `Chapter-1-Rational-Choice-Theory.md`.
- Keep math in LaTeX; one display equation per block.
- End long notes with a short **difficulty checklist** so readers know what is assumed.
