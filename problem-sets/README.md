# Problem Sets

Solutions organized by assignment: `ps01/`, `ps02/`, `ps03/`, …

## Suggested layout per problem set

```
ps01/
  solutions.tex      # or solutions.md
  notes.md           # alternative approaches, pitfalls, open questions
  figures/           # any plots used
```

- Write **your own** statement of each problem in a sentence or two, then the solution.
- Do **not** commit the official problem-set PDF — problems may be copyrighted, and
  solutions should stand on their own.
- Mark collaboration: if a solution came out of a group discussion, note the
  contributors in a short header comment.
